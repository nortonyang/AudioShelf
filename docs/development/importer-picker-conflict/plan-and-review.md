# 导入选择器冲突修复：规划与审核

## 目标

修复“导入 MP3”和“导入文件夹”点击后不弹出系统选择器的问题，同时保持 PDF 文件/文件夹关联入口可用。

## 当前证据与根因

- Computer Use 实测：资料库为空页的“导入 MP3”和“导入文件夹”按钮点击后没有出现打开面板。
- 对比实测：工具栏“关联 PDF 文件或文件夹…”可正常出现系统打开面板。
- `LibraryView` 在同一个根视图连续挂载三个 `.fileImporter`；实际运行中只有最外层的 PDF importer 响应。
- 扫描和导入服务尚未执行，因此问题位于选择器呈现层，而不是 MP3 扫描、metadata 或书签逻辑。

## 范围与非目标

- 将三个 `.fileImporter` 合并为一个共享选择器。
- 根据用户点击的入口动态配置允许类型、多选能力和完成处理器。
- 不修改 `LibraryImporter`、`PDFService`、数据模型或匹配规则。

## 原子任务与用户故事

**AT-001 / US-001**：作为用户，我希望点击任一导入入口都能看到正确的系统选择器，以便选择并导入内容。

验收标准：

1. 点击“导入 MP3”弹出仅允许 MP3、支持多选的面板。
2. 点击“导入文件夹”弹出可选择单个文件夹的面板。
3. 点击“关联 PDF 文件或文件夹…”弹出允许 PDF 与文件夹、支持多选的面板。
4. 取消面板不产生导入或错误；原有结果处理器保持不变。
5. 完整检查、Release 构建、签名验证和三入口 UI 复测通过。
