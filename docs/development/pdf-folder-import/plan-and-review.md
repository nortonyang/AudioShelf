# PDF 文件夹导入：规划与审核

## 目标

让“关联 PDF”文件选择器既能选择 PDF 文件，也能选择文件夹；选择文件夹后递归扫描其中的 PDF，并继续按文件名与资料库中的有声书唯一匹配。

## 当前证据

- MP3 文件夹导入已经由 `LibraryView` 和 `LibraryImporter.importFolder` 支持。
- PDF 关联目前只允许选择一个或多个 `.pdf` 文件。
- `PDFService.associate` 已实现同名唯一匹配、冲突保护、书签保存和事务式回滚。

## 范围与非目标

- 扩展现有 PDF 关联入口，接受 PDF 文件和文件夹的混合选择。
- 递归扫描文件夹，跳过隐藏文件和包目录，去重后再执行现有匹配。
- 在扫描期间保持用户所选文件夹的 security-scoped 访问授权。
- 不解析 PDF 内容，不改变匹配规则，不复制或删除用户文件。
