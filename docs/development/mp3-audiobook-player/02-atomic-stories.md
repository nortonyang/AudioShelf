# 原子任务与原子用户故事

## AT-101：建立原生应用工程

用户故事 US-101：作为开发者，我希望项目可直接由 Xcode 打开并具有清晰目录，以便继续开发和签名运行。

### 范围

- SwiftUI App、SwiftPM 清单、Xcode project、entitlements、README。

### 验收标准

- Given 完整 Xcode，When 打开 `AudioShelf.xcodeproj` 并运行，Then 构建 macOS App target。
- Given 只有命令行工具，When 执行 `swift build`，Then 同一源码能通过编译。

### 验证方式

- `swift build`；静态检查工程 build settings。

### 完成定义

- 工程骨架存在，应用入口可编译。

## AT-102：建立本地持久化模型

用户故事 US-102：作为用户，我希望书籍、章节与播放记录保存在本机，以便重启后仍保留资料库和进度。

### 范围

- SwiftData 的 Audiobook、Chapter、PlaybackRecord。

### 验收标准

- Given 两本书，When 分别播放到不同章节和时间，Then 两本书各自保存对应位置。
- Given 重新创建应用场景，When 读取 SwiftData，Then 记录仍可查询。

### 验证方式

- 编译、模型字段检查、完整 Xcode 中重启人工测试。

### 完成定义

- 模型容器创建成功，保存调用覆盖播放状态变化。

## AT-103：导入与自然排序

用户故事 US-103：作为用户，我希望导入 MP3 或文件夹，并看到 `第2章` 排在 `第10章` 前，以便按正确顺序收听。

### 范围

- 单文件、多文件分组、文件夹递归扫描、`localizedStandardCompare` 稳定排序。

### 验收标准

- Given `1.mp3`、`2.mp3`、`10.mp3`，When 导入，Then 章节顺序为 1、2、10。
- Given 空文件夹，When 导入，Then 显示“未找到 MP3”错误且不创建空书。

### 验证方式

- `swift test`；导入错误路径代码检查。

### 完成定义

- 导入服务返回已排序模型或本地化错误。

## AT-104：书签与 metadata

用户故事 US-104：作为用户，我希望重启后应用仍可读取原文件并显示内嵌封面，以便资料库长期可用。

### 范围

- 只读 security-scoped bookmark、陈旧刷新、章节重新定位、AVAsset metadata、默认封面回退。

### 验收标准

- Given 已授权文件夹，When 重启并播放，Then 从书签解析并访问章节。
- Given MP3 含 artwork，When 导入，Then 显示 artwork；若无 artwork，Then 显示默认封面。
- Given 源 MP3 已移动，When 为原章节重新选择文件，Then 保留进度并恢复后续访问。

### 验证方式

- 编译；完整 Xcode 沙盒运行人工测试。

### 完成定义

- 访问范围在播放期间保持、切换资源时释放；重新定位后保存新的只读书签。

## AT-201：资料库浏览

用户故事 US-201：作为用户，我希望搜索并按名称、导入时间或最近播放排序，以便快速找到有声书。

### 验收标准

- Given 多本书，When 输入标题、作者或章节关键字，Then 仅显示匹配书籍。
- Given 选择名称排序，When 标题含数字，Then 使用自然排序。

### 完成定义

- 资料库有空状态、网格、搜索、排序和删除入口。

## AT-202：图书与章节界面

用户故事 US-202：作为用户，我希望查看封面、书籍信息和章节列表，并从任意章节开始播放。

### 验收标准

- Given 一本多章节书，When 打开详情并双击章节，Then 加载并播放该章节。
- Given 有保存进度，When 打开详情，Then 显示总体进度并提供继续播放。

### 完成定义

- 详情页完整显示并能触发播放器。

## AT-203：播放器控制

用户故事 US-203：作为用户，我希望播放/暂停、上一章/下一章、拖动和调速，以便按偏好收听。

用户故事 US-204：作为用户，我希望切书或重启后从上次位置继续，以免重复寻找。

### 验收标准

- Given 已加载章节，When 使用所有控制，Then AVPlayer 状态与界面同步。
- Given 播放超过 5 秒，When 暂停或应用非活跃，Then SwiftData 保存当前书、章节和秒数。

### 完成定义

- 播放结束自动下一章；最后一章结束后停在结尾并标记完成。

## AT-204：封面与错误状态

用户故事 US-205：作为用户，我希望缺失封面或文件时看到可理解的界面，而不是应用无响应。

### 验收标准

- Given 无 artwork，When 展示书籍，Then 使用一致的默认封面。
- Given 文件被移走，When 播放，Then 显示错误且保留资料库记录。

### 完成定义

- 所有导入/播放失败进入统一警告提示。

## AT-301：跳转与睡眠定时

用户故事 US-301：作为用户，我希望快退 15 秒、快进 30 秒并设置睡眠定时，以便更适合睡前收听。

### 验收标准

- 跳转不会越过 0 或章节结尾。
- 15/30/60 分钟或本章结束定时到达后暂停并清除定时状态。

### 完成定义

- 控件可用且与持久进度一致。

## AT-302：最近播放与历史

用户故事 US-302：作为用户，我希望查看最近播放书籍和章节历史，以便快速返回。

### 验收标准

- 最近播放按 `lastPlayedAt` 倒序。
- 每次开始新章节创建记录，播放期间更新结束位置和完成状态。

### 完成定义

- 侧边栏可切换最近播放与历史。

## AT-303：验证与交付

用户故事 US-303：作为维护者，我希望获得构建说明、测试和已知限制，以便可靠接手。

### 验收标准

- `swift build` 与 `swift test` 通过。
- README 说明 Xcode 运行、沙盒权限、数据位置与人工验收。

### 完成定义

- 审核报告对所有故事给出证据或明确的人工验证项。
