# 移除详情页可见的重新定位菜单

## 目标

从图书详情页工具栏移除“重新定位章节…”下拉菜单，减少不常用控件对界面的干扰。

## 范围与非目标

- 删除 `BookDetailView` 中的可见下拉菜单。
- 保留章节右键菜单中的“重新定位此章节…”。
- 保留文件选择、书签刷新和错误提示等底层重新定位能力。
- 同步 README 中的功能说明和人工验收步骤。

## 原子用户故事

**US-001**：作为日常使用者，我希望图书详情页不显示低频的重新定位下拉菜单，同时在文件移动后仍可通过章节右键菜单恢复访问。

验收条件：

1. 图书详情页不再显示“重新定位章节…”下拉菜单。
2. 章节右键菜单仍显示“重新定位此章节…”。
3. 项目检查、核心测试、存储测试和 App 构建全部通过。
4. 新构建的 App 可通过 Finder 双击启动。

## 实施方案

1. 删除详情工具栏的 `Menu` 视图，不改动 `beginRelinking(_:)` 和相关服务。
2. 修改 README，只引导用户通过章节右键菜单执行重新定位。
3. 运行 `scripts/run_checks.sh`、`scripts/build_app.sh` 和签名验证，再重启应用。

## 开发交接

本次变更由用户直接要求 Codex 实施，无需 Gemini 代码开发交接。修改必须严格限制在上述 UI 和文档范围内。
